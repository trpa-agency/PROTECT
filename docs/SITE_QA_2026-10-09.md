## Warnings (recommend fix, not blocking)

- [Branding] Off-palette colors are deliberate data colors, not errors, but there is no shared map. The hub and rubrics use `#5BA4DD` (avalanche), `#8B5A3C` (debris flow), `#1C7293` (seiche), `#065A82` (high lake level); the criticality app, OD app, and tool use the ColorBrewer ramp `#2C7BB6`, `#FFFFBF`, `#D7191C` for criticality; the rubrics page uses orange and earth tints for contribution bars; the storm page uses `#5B9FDB`, `#93BFE7`, `#C45C1A`. Recommend one `hazardColor` map in the repo context file and the same criticality ramp everywhere.
- [Stack] The criticality and OD apps load ArcGIS 4.30; every other map page loads 4.31. Bump when those apps are next touched.
- [Stack] The criticality and OD apps use their own header (uppercase title, no agency eyebrow, no `h1`, no version chip, no footer) and a different info-popover pattern. They work, but they do not match the suite chrome. A header pass is scheduled with the Nov. 4 freeze.
- [Stack] AG Grids use `domLayout: autoHeight` without pagination (the stack skill asks for 25 rows per page). Deliberate for the hub and rubrics, which are reference tables meant to be read top to bottom; revisit if any grid grows past about 100 rows.
- [Stack] The climate and storm pages set Plotly trace colors explicitly rather than a `colorway`; charts stay on brand but new traces would default to Plotly colors.
- [Accessibility] The criticality app has 10 unlabeled inputs (sliders and the hazard threshold) and the OD app has five. Add `aria-label`s when those apps are next touched.
- [Accessibility] The two apps use a `div` for the page title; the heading hierarchy starts at `h3` or lower. Use an `h1`.
- [Responsive] The criticality and OD apps are fixed 324 px panels beside a full-height map with `body{overflow:hidden}`; at 375 px the map is a sliver. They are desktop tools; if a phone layout is wanted, stack the panel above the map as the tool page now does.
- [Performance] The storm events page is 3 MB because the culvert layer and the WRF grid are embedded. Documented in the repo context file; the plan is to swap the embedded culverts for the REST service.
