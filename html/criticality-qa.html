  • Cut the quarters only among segments above the floor, so the 13,000 segments at the lowest class on every input sit in quarter 0 and the rest split into three.
  • Call the top tenth "High" instead of the top quarter, which keeps the major roads and drops most one-step residential streets.
  • Keep the quarters and read criticality with the hazard: the Results page's hotspots need both a high vulnerability class and the top criticality quarter.

How the checks work
  • The checks run on the published criticality table, roads_criticality.json, with the default weights (traffic 0.3, detour 0.3, access 0.3, equity 0.1). Quarters are the Results page rule: percentile 75 and up is the top quarter.
  • Two segments touch when they share an endpoint. A "stub" is a segment of 16 m or less, below what the traffic join's minimum overlap can reach.
  • A segment can fail several checks; the table lists all of them, and the map colors it by the first open one.
  • Re-run python scripts/criticality_qa.py after every criticality rebuild; it writes criticality_qa.json, which this page reads.
